ABSTRACT

HireQuest is an advanced job matching system designed to assist job seekers and employers in identifying suitable job and candidate matches efficiently. Unlike traditional keyword-based platforms, this system implements a sophisticated multi-criteria filtering algorithm combined with AI Semantic Embeddings (Cosine Similarity) and Levenshtein Distance algorithms. This allows the system to semantically understand factors such as skills, work experience, education level, and job preferences.

Job seekers can upload resumes—which are parsed using Optical Character Recognition (OCR) via Tesseract.js and pdf-parse—and input relevant criteria. Employers can post job listings with specific requirements. Based on the calculated semantic matching percentage, the system ranks and recommends suitable jobs and candidates accurately. HireQuest supports user roles for job seekers and employers, and is developed as a modern web-based application using React, Node.js, Express, and MySQL. The system significantly improves matching accuracy, reduces mismatches, and enhances the overall recruitment process.

2.3 Semantic Embeddings and Multi-Criteria Algorithms

To overcome the significant limitations of traditional Boolean and keyword-based search systems, HireQuest incorporates advanced Artificial Intelligence techniques, specifically Semantic Embeddings and Levenshtein Distance algorithms.

2.3.1 The Limitation of Traditional Keyword Matching

Traditional systems often use techniques like TF-IDF (Term Frequency-Inverse Document Frequency) or basic string matching. While effective for exact matches, these fail to capture the meaning or context of words. For example, a candidate listing "Frontend Development" and an employer looking for "UI/UX Engineering" might be a strong match, but a strict keyword system would assign a match score of zero, causing the employer to miss out on a qualified candidate.

2.3.2 Semantic Embeddings using AI

According to Singla (2025), intelligent job recommendation systems based on semantic embeddings significantly improve matching accuracy by understanding the contextual meaning of words. Embeddings convert text into high-dimensional numerical vectors (arrays of floating-point numbers). Words or phrases with similar meanings are positioned closer together in this mathematical vector space. HireQuest utilizes Google Generative AI to generate these embeddings. By converting both the job requirements and the applicant's extracted skills into vectors, the system can mathematically determine their contextual similarity.

2.3.3 Cosine Similarity

To calculate the distance between the job vector and the candidate vector, HireQuest uses Cosine Similarity. Unlike Euclidean distance, which measures the straight-line distance and can be skewed by the length of the text (e.g., a very long resume vs a short job description), Cosine Similarity measures the cosine of the angle between two vectors. This ensures that the matching score focuses purely on the orientation (meaning) of the text rather than its magnitude (length), providing a more accurate matching percentage.

2.3.4 Levenshtein Distance for Typo-Tolerance

While semantic embeddings handle context, real-world data from OCR-extracted resumes often contains typographical errors (e.g., extracting "Jvascript" instead of "Javascript" from a slightly blurry PDF). To ensure that these minor errors do not severely penalize a candidate, HireQuest employs the Levenshtein Distance algorithm. This algorithm calculates the minimum number of single-character edits (insertions, deletions, or substitutions) required to change one word into another. By combining this with the semantic score in a Weighted Sum Model, HireQuest computes a final, transparent matching percentage for the user, ensuring both contextual understanding and keyword resilience.

2.4 Summary

The review of existing job portals like LinkedIn, JobStreet, and Indeed reveals a persistent reliance on exact keyword matching, which leads to inefficiencies for both job seekers and employers. By integrating AI-driven Semantic Embeddings, Cosine Similarity, and Levenshtein Distance, HireQuest proposes a modern, context-aware solution that provides transparent, highly accurate candidate matching.

3.4 Algorithm Design: Semantic Matching & WSM

The core innovation of HireQuest is the calculateMatchScore algorithm, executing on the Node.js backend. The algorithm uses a hybrid approach:

  1. AI Semantic Embedding (Cosine Similarity): The system generates text embeddings (high-dimensional floating-point vectors) for both the job description and the candidate's extracted skills using the Google Generative AI API.

    • The dot product and magnitudes of both vectors are calculated.
    • Cosine Similarity is computed: similarity = (A·B) / (||A|| * ||B||).
    • This similarity is scaled to generate a base AI Score out of 100%.

  2. Levenshtein Distance (Keyword Resilience): To catch explicit skill requirements, the algorithm checks individual skills. If a skill doesn't match perfectly, it uses Levenshtein Distance to calculate string edit distances, successfully matching typos or slight variations (e.g., "Javascript" vs "Java Script").

  3. Weighted Sum Model (WSM): The final match score is a weighted combination of the AI Semantic Score (which understands context) and the Keyword Score (which ensures hard requirements are met).

4.3 Coding Snippet: The Matching Algorithm

Below is an excerpt of the implementation from the Node.js backend demonstrating the Cosine Similarity calculation for semantic embeddings:

// Calculate Cosine Similarity between Seeker and Job Embeddings
const vecA = JSON.parse(seekerEmbeddingStr);
const vecB = JSON.parse(jobEmbeddingStr);

let dotProduct = 0, normA = 0, normB = 0;
for (let i = 0; i < vecA.length; i++) {
  dotProduct += vecA[i] * vecB[i];
  normA += vecA[i] * vecA[i];
  normB += vecB[i] * vecB[i];
}

if (normA > 0 && normB > 0) {
  const similarity = dotProduct / (Math.sqrt(normA) * Math.sqrt(normB));
  // Scale similarity to a percentage score
  let score = (similarity - 0.65) * 400; 
  aiScore = Math.max(0, Math.min(100, Math.round(score)));
}

  2. OCR Accuracy: While Tesseract.js and pdf-parse are powerful, highly graphical or unconventionally formatted PDF resumes may result in garbled text extraction, lowering the candidate's match score artificially.

5.4 Recommendations

For future iterations of the HireQuest platform, several enhancements can be made:

  1. Local LLM Integration: To reduce dependency on external APIs, a lightweight, locally hosted Large Language Model (LLM) could be integrated to handle semantic embeddings natively.
  2. Interview Scheduling Module: Adding an automated calendar system where companies can schedule interviews directly within the platform.
  3. Advanced Resume Builder: Providing an in-house resume building tool to standardize formatting, completely bypassing the need for complex OCR extraction.

5.5 Conclusion

In conclusion, HireQuest serves as a comprehensive, intelligent digital platform that modernizes the recruitment process. By successfully applying machine learning concepts—specifically Semantic Embeddings and Levenshtein Distance—the system achieves its objective of accurately filtering and matching candidates to suitable companies. With continuous improvements, HireQuest has the potential to become an indispensable tool for the modern workforce.
